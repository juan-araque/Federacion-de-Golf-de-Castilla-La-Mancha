# 🏌️‍♂️ Web Oficial — Federación de Golf de Castilla-La Mancha

Desarrollo, maquetación y migración a producción del sitio web oficial de la **Federación de Golf de Castilla-La Mancha**. Proyecto realizado de forma colaborativa durante nuestro periodo de prácticas de Desarrollo de Aplicaciones Web (DAW) entre **mayo y junio de 2025**.

🌐 **Sitio en producción:** [https://fedgolfclm.com/]

---

## 📋 Descripción del Proyecto

El objetivo principal fue diseñar y construir desde cero la plataforma web de la federación para centralizar la información institucional, competiciones, clubes federados y noticias del sector en la región.

El desarrollo se dividió en **dos fases clave**:
1. **Prototipado y Maquetación Estática:** Creación de la arquitectura completa del sitio mediante una amplia estructura de páginas en HTML5, hojas de estilo personalizadas en CSS3, interactividad en JavaScript y apoyo de scripts en Python para automatización/procesamiento de datos durante el desarrollo.
2. **Migración a CMS (WordPress / PHP):** Adaptación e integración de toda la estructura estática previa a un entorno dinámico sobre **WordPress** utilizando **PHP**, permitiendo al cliente gestionar contenidos de forma autónoma sin perder el diseño a medida.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend & CMS:** PHP, WordPress (desarrollo e integración de plantillas a medida)
* **Scripting / Utilidades:** Python
* **Control de Versiones:** Git & GitHub

---

## ✨ Características Principales

* **Arquitectura multipágina:** Amplia estructura de secciones adaptadas a las necesidades de jugadores, clubes y torneos de la federación.
* **Diseño Responsive:** Maquetación adaptada a dispositivos móviles, tablets y escritorio.
* **Migración a Producción:** Paso completo desde código estático (`HTML/CSS/JS`) a un tema/estructura funcional en WordPress listo para autogestión.
* **Trabajo Colaborativo:** Coordinación de ramas, integración de código y reparto de vistas entre los tres desarrolladores.
